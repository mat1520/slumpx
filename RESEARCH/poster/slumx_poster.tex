\block{Abstract}{
The Internet of Things has fundamentally transformed cybersecurity, introducing billions of connected devices with minimal security measures. This research presents a comprehensive technical analysis of the SlumX botnet (Hitori variant) through static code analysis of the open-source repository [1][2].

\vspace{1em}
\textbf{Key Focus:} Understanding the evolution from simple credential attacks to sophisticated multi-architecture IoT malware with advanced evasion capabilities [3][4].

\vspace{1em}
\textcolor{OrangeAccent}{\textbf{Impact:}} With over 26 billion IoT devices projected by 2030 [5], understanding botnet evolution is critical for developing effective defensive strategies.
}

\block{Research Objectives}{
\textbf{General Objective:}
\begin{itemize}
    \item Conduct in-depth technical analysis of Hitori (SlumX) variant to understand modern IoT botnet threats
\end{itemize}

\vspace{1em}
\textbf{Specific Objectives:}
\begin{itemize}
    \item Analyze core architecture and operational framework
    \item Examine Command \& Control infrastructure design
    \item Identify and categorize DDoS attack vectors [6][7]
    \item Evaluate multi-architecture support mechanisms
    \item Document evasion and anti-analysis techniques [8]
    \item Assess IoT device scanning and exploitation capabilities [9][10]
\end{itemize}

\vspace{1em}
\colorbox{TealAccent!15}{\parbox{0.95\linewidth}{\small
\textbf{Methodology:} Static code analysis of 15,000+ lines of C source code from GitHub repository, examining binary compilation artifacts, network protocol implementations, and cross-architecture support mechanisms.
}}
}

\block{Methodology}{
\textbf{Static Code Analysis Framework}

Analysis of the \texttt{mat1520/slumpx} repository using:

\begin{itemize}
    \item \textbf{Code Review:} Systematic examination of source files (\texttt{bot.c}, \texttt{server.c}, \texttt{scankill.c})
    \item \textbf{Control Flow Analysis:} Mapping execution paths and decision points
    \item \textbf{Threat Modeling:} Assessment of attack capabilities and defensive gaps
    \item \textbf{Architecture Analysis:} Cross-platform compilation and targeting strategies
\end{itemize}

\vspace{0.5em}
\textbf{Limitations:}
\begin{itemize}
    \item Static analysis cannot capture all runtime behaviors
    \item No testing on actual IoT devices
    \item Temporal snapshot of evolving malware
\end{itemize}
}

\block{Key Findings \& Research Contributions}{
\vspace{0.5em}
\begin{itemize}
    \item \textcolor{BlueCorp}{\textbf{Multi-architecture support:}} 12 architectures (MIPS, ARM, x86, PowerPC, SPARC, M68k, SH4) dramatically expanding attack surface across diverse IoT ecosystems [14][15]
    
    \item \textcolor{BlueCorp}{\textbf{Advanced evasion techniques:}} Process masquerading, anti-debugging mechanisms, IoT-specific hiding techniques demonstrating sophistication beyond traditional malware [8]
    
    \item \textcolor{TealAccent}{\textbf{Targeted exploitation:}} Vendor-specific exploits (D-Link, Netgear, Hikvision) and protocol-based attacks showing evolution from opportunistic to targeted strategies [9][13]
    
    \item \textcolor{OrangeAccent}{\textbf{Implementation vulnerabilities:}} Buffer overflow risks, hardcoded credentials, predictable attack patterns creating defensive opportunities [17]
\end{itemize}

\vspace{1em}
\colorbox{TealAccent!15}{\parbox{0.95\linewidth}{\small
\textbf{Novel Contribution:} First comprehensive static analysis of SlumX (Hitori) variant, documenting architectural evolution from Mirai lineage and identifying critical security gaps for IoT defense strategies.
}}
}

\block{Conclusions \& Future Research}{
\vspace{0.5em}
This analysis reveals significant advancement in IoT malware sophistication, particularly in multi-architecture targeting and evasion capabilities. The findings demonstrate evolution from opportunistic to targeted IoT attacks, with implications for both offensive and defensive cybersecurity strategies [18].

\vspace{1em}
\colorbox{BlueCorp!10}{\parbox{0.95\linewidth}{\small
\textbf{Defensive Implications:}
\begin{itemize}
    \item Network-level detection must account for multi-protocol attack vectors
    \item Device hardening requires architecture-specific security measures
    \item C\&C disruption strategies should target infrastructure weaknesses
\end{itemize}
}}

\vspace{1em}
\textcolor{BlueCorp}{\textbf{Future Research Directions:}}
\begin{itemize}
    \item Dynamic analysis frameworks for multi-architecture IoT malware [19]
    \item Machine learning-based detection for resource-constrained devices [20]
    \item Comparative analysis of botnet evolution patterns (Mirai → Bashlite → SlumX)
    \item Honeypot deployment strategies for early threat detection [10]
\end{itemize}
